## 📖 О проекте

**NovaLab** — это современный образовательный конструктор, позволяющий собирать транспортные средства в интерактивном 2D и 3D режимах. Проект направлен на развитие инженерного мышления и понимания принципов сборки механизмов.


## 🛠️ Технологии

| Категория | Технологии |
|-----------|------------|
| **Frontend** | React 19, Vite 7 |
| **3D Графика** | Three.js, React Three Fiber, React Three Drei |
| **Анимации** | Framer Motion |
| **Стили** | CSS Modules |

## 🚀 Быстрый старт

### Требования

- [Node.js](https://nodejs.org/) версии 18+ (рекомендуется LTS)
- npm или yarn

### Установка

```bash
# Клонируйте репозиторий
git clone https://github.com/your-username/novalab.git
cd novalab

# Установите зависимости
npm install

# Запустите проект
npm run dev
```

### Windows (альтернативный способ)

1. Распакуйте архив проекта в любую папку
2. Дважды кликните на файл `start.bat`
3. Подождите 1-2 минуты при первом запуске
4. Проект откроется автоматически в браузере!

Проект будет доступен по адресу: **http://localhost:5173**

## 🎮 Режимы работы

### 🔧 2D Режим
Идеально для начинающих — собирайте простые схемы:
- Лампочка с выключателем
- Пропеллер с мотором
- Базовые электрические цепи

### 🚗 3D Конструктор машины
Полноценная сборка автомобиля из 11 деталей:
- Шасси, колёса (4 шт), двигатель
- Аккумулятор, пульт управления, кузов

**После сборки** — запустите симуляцию и управляйте машиной с помощью `WASD`!

### 🚀 3D Конструктор ракеты
Соберите многоступенчатую ракету:
- Командный модуль и обтекатель
- Первая и вторая ступени
- Боковые ускорители

## ❓ Решение проблем

| Проблема | Решение |
|----------|---------|
| Node.js не найден | Установите с [nodejs.org](https://nodejs.org), перезагрузите ПК |
| Порт 5173 занят | Закройте другие приложения или измените порт в `vite.config.js` |
| Не открывается браузер | Откройте вручную: `http://localhost:5173` |
| Ошибка 3D рендеринга | Обновите драйверы видеокарты, используйте современный браузер |
